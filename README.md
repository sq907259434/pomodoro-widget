# 番茄钟 · PomodoroCard

贴在桌面上的番茄钟小卡：两种模式——普通倒计时、番茄钟循环（专注 → 休息 → 专注）。到点响铃 + 系统通知，设置和提示音在卡片旁的独立浮窗里调。

## 两种模式

| 模式 | 怎么进 | 行为 |
|---|---|---|
| 普通倒计时 | 滚轮调到分钟数，点播放 | 走完就结束，不循环 |
| 番茄钟循环 | 右键 →「专注 25 分钟」/「专注 50 分钟」 | 专注结束 → 自动休息 5 分钟 → 再回专注，循环 |

## 特性

- **圆柱滚轮**：中间最大、上下逐渐变小变淡，0–60 首尾相接；往下滚是递增
- **数字和刻度一起滚**：滚动时数字带与刻度带同相位平移，松手归位换值
- **液位**：设定时间后，竖线从顶端到圆点是「琥珀→红」渐变
- **番茄钟循环**：专注 / 短休息 / 长休息三阶段，顶部显示「专注 · 第 N 轮」
- **到点提醒**：整卡红闪 + 响铃 + 系统通知（专注结束提示休息，休息结束提示继续）
- **日间 / 夜间主题**：右键 → 主题 → 跟随系统 / 浅色 / 深色
- **双击改时间**：就地输入分钟数，回车确认 / Esc 取消
- **常驻桌面**：卡片贴在桌面层，Win+D 不会把它收走
- **透明背景**：桌面层里垫一张桌面快照，可调透明度
- **所有窗口置顶**：右键菜单一个开关

## 用法

| 操作 | 行为 |
|---|---|
| 滚轮 | 调分钟（0–60 循环，普通倒计时） |
| 双击数字 | 就地输入 |
| 点播放 | 开始倒计时 |
| 点暂停 | 停住，再点继续 |
| 左下重置 | 普通倒计时重来 / 番茄钟归零回第 1 轮 |
| 右键 | 专注 25/50 分钟、跳过当前阶段、提示音、设置、置顶、开机自启 |
| 按住卡片拖动 | 移动位置（位置会记住） |

## 设置浮窗

右键 →「设置（番茄钟 / 外观）…」：

- 专注 / 休息 / 长休息时长
- 长休间隔（每 N 轮长休一次，0 = 关）
- 自动循环开关
- 透明度、主题

## 开发

```bash
npm install
npm start          # 直接跑
npm run dist:dir   # 打包到 dist/win-unpacked
npm run icon       # 重新生成图标（tools/make-icon.js + tools/pack-ico.py）
```

文件分工：

```
main.js            主进程：窗口 / 贴桌面层 / 快照调度 / 拖动 / 输入桥 / 番茄钟配置
widget.html        界面全部：布局、CSS、滚轮与计时状态机
backdrop.js        桌面快照抓取与裁剪
desktop-layer.js   SetParent 进 Progman 那套
look.html          设置浮窗（番茄钟参数 / 外观）
sound.html         提示音浮窗
ime.html           幽灵输入窗（桌面层里拿不到键盘焦点，靠它代收）
tools/             图标生成
```

## 已知限制

- 桌面层模式下卡片拿不到键盘焦点，所有输入走幽灵输入窗转发；**不注册任何全局快捷键，右键菜单项也不挂任何快捷键（F5/F6 之类一律不留）**，所有操作走右键菜单点击
- 桌面快照会在交互后 0.4 秒、以及每 20 秒自动重抓
- 只在 Windows 上验证过
